# v0.1.0-alpha.3

This release adds the interaction safety guard for asynchronous factory ticks and documents a live multiplayer validation of the guarded bridge on the validated Linux Satisfactory Dedicated Server build.

## Changes in alpha.3

- Added a re-entrant Game Thread mutation guard around buildable, conveyor, tick-group, and inventory mutations.
- Mutations wait for in-flight asynchronous factory ticks to drain before changing engine-owned actor or inventory state.
- Eligible factory ticks fall back synchronously while a protected mutation is active.
- Added runtime counters for active mutations, mutation waits, and completion-pool reuse.
- Added anonymized live validation evidence for a connected player: 1,784 of 1,784 ticks completed asynchronously, with no fallbacks, backlog, assertions, fatal signals, or critical errors during the observation window.
- Updated the observation tooling and release documentation for the current bridge behavior.
