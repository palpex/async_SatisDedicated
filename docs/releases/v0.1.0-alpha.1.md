# v0.1.0-alpha.1

This first release packages the experimental TaskGraph bridge for the validated Linux Satisfactory Dedicated Server build. It keeps eligible factory simulation asynchronous and routes detected conveyor-chain actor migrations through the Game Thread to preserve Unreal's actor lifecycle contract.

## Included

- Native `libsatis_task_bridge.so` build and ABI validation.
- TaskGraph worker dispatch and completion-event chaining.
- Conveyor migration detection with `satis_async_sync_fallback_count()`.
- English installation, systemd, observation, and rollback instructions in [`docs/installation.md`](../installation.md).
- Safety, runtime-evidence, and binary-integrity tests.
- Missing completion/bind failures now execute inline instead of dispatching untracked work.
- Additional guards for custom tick handlers, unsupported FactoryGame layouts, and GC/package-save state at entry.
- Removed the unsafe IsInGameThread override and task-tag spoofing; worker calls report their actual scheduling lane.
- A completed-tick counter, anonymous bounded observation tool, and sanitizer regression tests.

## Compatibility

Targets Steam App `1690800`, Linux depot `1690802`, public build `25782485`, Core GNU Build-ID `36a6397531db8df2`, Engine ID `b50bbe682205dc29`, and FactoryGame ID `7dd11ed7c1cc5e43`. Linux x86-64 binary requires glibc 2.34+ and CXXABI_1.3.9. Other builds are unsupported until separately analyzed.

## Validation and observations

- Current bridge control-flow and launcher tests pass locally, including the scheduling/completion regression harness under address/undefined-behavior sanitizers. Historical ABI probe files also validate.
- [Release-candidate observation](https://github.com/palpex/async_SatisDedicated/blob/v0.1.0-alpha.1/evidence/runtime/release-candidate-observation.json): 120 seconds, 3,464 additional completed async ticks, no assertions/fatal signals, zero connected players. Includes startup samples; do not treat them as steady-state performance.
- Candidate library SHA-256: `3f21cd34d4b68097ba72bca0c5a355d734b481fa0ebe0be1a5f58577bfc42665`.
- No repeated player-building test has yet been completed for this exact candidate. Earlier tests used a previous library. Inventory warnings remain recorded.
- Earlier CPU-reduction/jitter and synthetic-server-TPS claims have been corrected. Real gameplay speedup remains unproven; see [measurement limits](https://github.com/palpex/async_SatisDedicated/blob/v0.1.0-alpha.1/docs/performance_benchmarks.md).

Download `async-satis-v0.1.0-alpha.1-linux-x86_64.tar.gz` and its `.sha256` file from this release, verify the checksum, and follow [installation and rollback](https://github.com/palpex/async_SatisDedicated/blob/v0.1.0-alpha.1/docs/installation.md). Official server binaries and saves are not included.

## Alpha limitations

This is an experimental preload bridge. Unreal UObject lifetime, garbage-collection timing, world transitions, and all non-factory subsystems are not made generally thread-safe by this release. Actor creation and component registration remain Game-Thread operations. Disable the bridge if the server produces a fatal assertion, crash, or save-integrity warning correlated with the test.

Performance claims are workload-specific measurements and are not a guarantee for every save, CPU, server build, or player action.
