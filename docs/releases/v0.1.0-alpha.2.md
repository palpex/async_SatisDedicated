# v0.1.0-alpha.2

This second alpha release adds a synchronous fallback guard for pending incremental garbage-collection reachability analysis and packages the updated TaskGraph bridge for the validated Linux Satisfactory Dedicated Server build.

## Changes in alpha.2

- Added synchronous Game Thread fallback when `UE::GC::GIsIncrementalReachabilityPending` is set at tick entry. `TickFactoryActors` invokes `UE::GC::MarkAsReachable` during incremental GC, which is an internal UObject mutation unsafe on background worker threads.
- Documented confirmed historical crash root cause in [`docs/crash-investigation-2026-10-27.md`](../crash-investigation-2026-10-27.md): un-guarded conveyor migration invoked `UWorld::SpawnActor` and `AActor::FinishSpawning`, failing Unreal Engine's `IsInGameThread()` assertion.
- Added post-deployment runtime observation ([`evidence/runtime/guarded-incremental-observation.json`](../evidence/runtime/guarded-incremental-observation.json)) verifying active multithreaded ticks on the production server host.
- Updated unit and contract test suite to 13/13 passing tests under AddressSanitizer and UndefinedBehaviorSanitizer.
