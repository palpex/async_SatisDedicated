# v0.1.0-alpha.5

This release combines the asynchronous factory tick bridge with a separate
synchronous fix for the pipeline attachment/pump dismantle crash.

## Changes

- Added `libsatis_pipeline_guard.so`. If a connected pipe component has a null or
  non-pipeline owner, attachment dismantling uses the original base path and skips
  optional pipe merging instead of triggering `O != nullptr`.
- The launcher and release archive now include both libraries. Existing
  `LD_PRELOAD` entries are preserved; explicit missing guard paths are rejected.
- Added sanitized crash findings and native regression tests for the guard,
  including missing owners, derived pipeline classes, peer flags, heap cleanup,
  and live replacement publication.
- Included the live guard installer for compatible running servers.
- Added a bounded server supervisor with startup grace periods, systemd recovery,
  API-port compatibility repair and private diagnostics. Fixed the observer’s
  active-mutation counter width to match the native 32-bit atomic.

The latest confirmed crash also occurred with the async library unloaded. Its
stack is in a player dismantle RPC on the Game Thread and differs from the
historical worker tick failures. The guard fixes this observed null-owner path;
the identity and original cause of that owner state remain unobserved.

## Compatibility and verification

Targets Steam build `25782485` only. The guard verifies FactoryGame build ID
`7dd11ed7c1cc5e43` and relevant instruction prefixes; the async bridge retains
its existing engine compatibility checks. Official binaries and save files are
excluded from release assets.

Local build, **23 automated tests**, and stored runtime evidence checks passed
before publication. The new native guard tests use AddressSanitizer and
UndefinedBehaviorSanitizer. The archive includes `SHA256SUMS` for both project-owned libraries
and `SOURCE_COMMIT` for source provenance. The separate archive checksum covers
the complete download.

Production restarted with both libraries at **2026-10-30 23:58:23 UTC**. The
first observation recorded **531/531 completed async ticks**, zero in-flight
ticks or synchronous fallbacks, zero fatal log matches, and a healthy API at
**29.81 TPS** with no connected players. [Startup evidence](../../evidence/runtime/async-alpha5-startup-2026-10-31.json).

The requested two-hour observation is **running**, with a deadline of
**2026-10-31 01:59:09 UTC (02:59:09 CET)**. The host-local supervisor and existing
systemd restart policy provide automatic recovery. A successful startup is not a
